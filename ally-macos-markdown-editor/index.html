Introducing the Ally macOS markdown editor

The Ally markdown editor is central to the Ally experience. For this reason, I wanted to make sure the markdown editor is top notch, not an afterthought. I wanted it to standalone, so that someone could use Ally even if they aren’t interested in its AI features.

The critical criteria:

  • Lightweight - It needs to launch quickly, have a snappy UI, and not get bogged down by background processes.
  • Beautiful & personalized - Your workspace should be comfortable and pleasant for you.
  • Flexible file management - No rigid structure or unecessary limitations imposed so you can organize your files how you see fit.
  • Accessible files - You should be able to easily access your files in a flat folder system as .md files any time (no proprietary databases or sloppy exports needed).

Pretty standard requirements for a markdown editor — nothing ground-breaking there. But, it was also important that the Ally markdown editor be AI-first. Ally is the first markdown editor with AI built into its foundation rather than something that was tacked on later.

This is key because Markdown is “the common language between AI and humans.” This makes it the ideal syntax for human-AI collaboration, which is what Ally is built for.

Ally needs to be able to know what you’re working on and be able to work on it alongside you. This means there’s a lot of hidden processes happening as you work.

Learn more about the Ally Markdown Editor or download the free app in the App Store.
